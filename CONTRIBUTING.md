# Contribuer

Merci de votre intérêt pour Pilbo !

- Pour un bug ou une idée, ouvrez une issue.
- Pour une pull request, vérifiez que `make tests` passe (`make help` liste toutes les commandes).

## Droits sur les contributions

En proposant une contribution, vous accordez à l'auteur de Pilbo le droit d'utiliser, de modifier et de distribuer votre contribution sous toute licence, y compris commerciale.
