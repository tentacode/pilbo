- [ ] modifier une prise d'un jour, passé ou aujourd'hui : changer le statut (prise, ignorée, aucune action) et l'heure de la prise, avec le stock.

Pouvoir modifier la prise sur un jour (Aujourd'hui ou un autre jour). Pour aujourd'hui seulement les prises validées (pas les prises sans actions). Pour les jours précédents toutes les prises peuvent être changées (pris -> ignoré ou annuler la prise, ignoré -> pris ou annuler la prise, aucune action -> pris ou ignoré). Les jours précedents n'ont pas les boutons "Prendre ou Ignorer", ils restent uniquement sur "Aujourd'hui".
