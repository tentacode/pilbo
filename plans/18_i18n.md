# Spec 18 — Internationalisation (FR / EN)

## Contexte

App en français et en anglais, changement de langue instantané depuis les réglages. Clés = texte FR, un namespace par feature, extraction automatique avec `i18next-cli`. Spec et décisions : `specs/18_i18n.md`.

À lire avant de commencer :

- `CLAUDE.md` (dont « App tone »), `docs/architecture.md`, `docs/notifications.md`.
- Code existant :
  - Langue : `src/features/settings/hooks/useAppLanguage.ts`, `utils/resolveLanguage.ts`, `store/settingsStore.ts`, `components/LanguageRow.tsx`, `SettingsScreen.tsx` (`SCREEN_TITLES`, PoC à remplacer).
  - Textes hors composants : constantes `const LABEL = "…"` (ex. `features/settings/components/*Row.tsx`, `pillbox/MedScreen.tsx`), `shared/navigation/tabs.ts` (`formatBadgeLabel`), `shared/error-handling/utils/contactSupport.ts`.
  - Pluriels et dates : `features/today/utils/formatters.ts` (`DAY_NAMES`, `MONTH_NAMES`, `pluralize`), `features/stocks/utils/formatters.ts` (« 1er »), `features/settings/utils/formatters.ts`, `features/pillbox/utils/formatters.ts` (`SHORT_DAY_NAMES`), `pillbox/utils/medDraft.ts` (`LOCALE`).
  - Heure : `src/domain/intake.ts` (`formatIntakeTime`), `features/pillbox/components/IntakeTimeRow.tsx` (`PICKER_LOCALE`).
  - Notifications : `features/notifications/rescheduleReminders.ts`, `utils/planReminders.ts`, `utils/planLowStockAlerts.ts`, `utils/formatters.ts`.
  - Le design system n'a aucun texte en dur (déjà conforme).

Règles pour toutes les étapes :

- Composants : `useTranslation("<namespace>")`.
- Fonctions pures (formatters) : reçoivent `t` en paramètre (testables, re-rendu garanti par le composant appelant). Penser aux `useMemo` qui doivent dépendre de la langue.
- Code hors React (notifications) : `i18n.t` directement.
- Traduction EN : ton de « App tone », sans jargon.
- Aucune migration ni rétrocompatibilité.
